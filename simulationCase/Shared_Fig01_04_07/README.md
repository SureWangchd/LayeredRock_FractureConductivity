# Shared data for manuscript Figures 1, 5 and 8

Run `python run_replot.py`. The `scripts/jgrse_figures`, `runs` and `source_data` relative paths are required. Python dependencies: numpy, scipy, pandas, matplotlib, Pillow. Outputs go to `replots/`. All original numerical rows and the completed n=2 plot marker are retained.

Figure 1 uses the exact flat-layer background conductivity, 1/55 S/m. Original M1 reference values and gains are preserved in separate CSV columns; target conductivities are unchanged.
