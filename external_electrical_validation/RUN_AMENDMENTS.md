# 数值执行记录

初始输入方案在首次电学预测前写入 `INPUT_PROTOCOL.json`，指纹和UTC时间保存在 `runs/input_freeze.json`。这是公开数据的回顾性外部检验；不声称在不知道观测值时预注册。

1. 原生OCC薄椭球表面三角化出现自交和重复点错误，未产生有效求解结果。改为先对球和沿z伸长的盒子划分网格，再将所有节点的z坐标乘以纵横比。在真实物理坐标中重新组装有限元矩阵，保留原定椭球、体积分数和材料。失败不涉及修改任何实验值。
2. 初始三档网格完成后，总电导率已较稳定，但垂直方向的小增量仍有约5.6%的相邻网格变化，因此增加第四档网格（level 3）量化该差值的数值敏感性。没有改动几何、材料或背景标定，也没有以是否落入2%实验误差作为加密停止条件。最终同时报告总量和增量的网格变化。
3. 采用原文报告的电导率±2%、孔隙率±0.0001，传播到背景校准与预测。上下界是固定名义模型下的确定性容差包络，不是统计置信区间；几何、盐水和孔隙率闭合的情景另行报告。
